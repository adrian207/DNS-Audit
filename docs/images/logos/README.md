# Logo and Branding Assets

Project logos and branding materials for DNS Master Audit.

## Required Assets

### Primary Logo Files

1. **Main Logo** (Priority: Medium)
   - Filename: `logo.png`
   - Size: 512x512px
   - Format: PNG with transparency
   - Usage: GitHub, documentation, general use

2. **Dark Mode Logo** (Priority: Medium)
   - Filename: `logo-dark.png`
   - Size: 512x512px
   - Format: PNG with transparency
   - Usage: Dark-themed documentation, presentations

3. **Favicon Sizes** (Priority: Low)
   - Filenames: `logo-32x32.png`, `logo-64x64.png`
   - Usage: Browser icons, small UI elements

4. **Vector Logo** (Priority: High)
   - Filename: `logo.svg`
   - Format: SVG
   - Usage: Scalable, preferred for all uses

### Supplementary Assets

5. **Social Media Preview** (Priority: High)
   - Filename: `social-preview.png`
   - Size: 1280x640px
   - Format: PNG
   - Usage: GitHub social preview, Twitter cards, LinkedIn

6. **Banner/Header** (Priority: Low)
   - Filename: `banner.png`
   - Size: 1200x400px (or similar wide format)
   - Usage: README header, documentation sites

## Design Guidelines

### Logo Elements (Suggestions)

Consider incorporating:
- 🌐 DNS server icon (globe with circuit lines)
- 🔍 Magnifying glass (audit/inspection)
- 🛡️ Shield (security)
- ⚡ PowerShell references (if licensing allows)
- 🪟 Windows Server motifs (subtle, if allowed)

### Color Palette

**Primary:**
- Microsoft Blue: `#0078D4`
- Success Green: `#107C10`

**Accent:**
- Orange (warning): `#FF8C00`
- Red (error): `#D13438`

**Neutral:**
- Gray: `#605E5C`
- Background: `#FFFFFF` / `#1E1E1E` (dark mode)

### Typography

- Primary: Segoe UI Bold (or Arial Bold)
- Monospace: Consolas or Courier New

## Creating Logos

### Tools

**Free:**
- [Canva](https://www.canva.com/) - Templates and easy editing
- [Figma](https://www.figma.com/) - Professional design tool
- [Inkscape](https://inkscape.org/) - Vector graphics (SVG)

**Stock Assets:**
- [Icons8](https://icons8.com/) - Icons and graphics
- [Font Awesome](https://fontawesome.com/) - Icon fonts
- [Unsplash](https://unsplash.com/) - Background images

### Process

1. **Sketch concept** - Paper or digital
2. **Create in design tool** - Canva, Figma, or Inkscape
3. **Export required sizes**:
   ```
   logo.svg (vector - master file)
   logo.png (512x512)
   logo-dark.png (512x512)
   logo-32x32.png
   logo-64x64.png
   ```
4. **Create social preview** (1280x640)
5. **Optimize file sizes**
6. **Upload to GitHub**:
   - Logo files: This directory
   - Social preview: Repository Settings → Social preview
